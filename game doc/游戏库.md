# SfG 游戏标准库

SfG（Sublimation for Game）给 Sublimation 提供「写网页游戏」的标准库：所有游戏能力都是
`@game` 标注的**无体桥接函数**——声明在 `.subl` 里、函数体由壳工程的
`game-app/js/game-runtime.js` 用 KAPLAY 实现。**宿主桥 ABI（t38 定案；t43 全链路统一）**：宿主提供 `globalThis.__subl.call(op, args)` 单入口分派（`__SG_OPS` 注册表，op 名 = 声明的函数名；`__subl.ops()` 枚举 45 op；未知 op 抛明确错误）；编译器（t43）对用户 `@host` 无体声明也统一生成单入口调用，运行时闭包封装、零桥全局污染（t40 过渡期的裸名实现已回撤）。
Sublimation 侧不需要知道 KAPLAY，只看到这 45 个声明。

## 桥接模型

```subl
@game @host @impure fun onKeyDown(key: Str, body: (Any) => Null): Null
```

- `@game`：游戏内建标记。注解处理器 `game.subs` 据此做白名单与态度校验（见
  [注解处理器与打包](注解处理器与打包.md)）。
- `@host` + 无体：编译器不生成函数定义，调用点翻成宿主桥单入口
  （`onKeyDown("left", ...)` → JS `globalThis.__subl.call("onKeyDown", ["left", ...])`）。
- `@impure`：桥接有副作用，符合语言的纯净性纪律（缺失会被处理器警告）。
- 运行期由壳工程的 `game-runtime.js` 提供 `globalThis.__subl.call` 分派：宿主侧 `__SG_OPS` 注册表（单一真源，op 名与这里的声明一一对应，与 game.subs 处理器的 op 白名单对齐）转发到 KAPLAY 上下文 API；未知 op 抛明确错误。

## 类型约定

| Sublimation 类型 | 含义 |
| --- | --- |
| `Rat` | 所有的坐标、尺寸、时间间隔、速度（JS number） |
| `Nat` | 视口宽高等非负量 |
| `Str` | 键名、标签、十六进制颜色、文本 |
| `Any` | 游戏对象（game object）、组件、Vec2——KAPLAY 对象对 Sublimation 不透明 |
| `List[Any]` | `objsByTag` 的返回（编译器内建 List，无需挂载 core） |

- **没有运算符优先级**：`a + b * c` 是左结合，乘法必须显式括号：`a + (b * c)`。
- **块体返回值**：lambda 体里写尾表达式不会自动返回，要 `return`。
- 编译器内建的 `rand()`、`toStr()`、`concat()` 不用挂载 core 即可用（`@root` 特化）；
  挂载 `core/` 后还有完整的字符串/数学/集合标准库。

## API 总表（45 个）

### 启动与场景（`game.subl`）

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `gameStart` | `(width: Nat, height: Nat): Null` | 初始化 KAPLAY 画布（`global: false`），游戏入口必须最先调用 |
| `gameGravity` | `(g: Rat): Null` | 设置重力加速度（像素/秒²） |
| `sceneAdd` | `(name: Str, body: (Any) => Null): Null` | 注册场景及其初始化函数 |
| `sceneGo` | `(name: Str): Null` | 切换/重启场景（重开等） |
| `viewWidth` | `(): Nat` | 视口宽 |
| `viewHeight` | `(): Nat` | 视口高 |

### 精灵与组件（`sprite.subl`）

组件（KAPLAY component，传给 `objUse` 组装对象）：

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `compSprite` | `(name: Str): Any` | 精灵渲染（需先 `spriteLoad`） |
| `compPos` | `(x: Rat, y: Rat): Any` | 初始位置 |
| `compScale` | `(s: Rat): Any` | 缩放 |
| `compRect` | `(w: Rat, h: Rat): Any` | 矩形渲染 |
| `compCircle` | `(r: Rat): Any` | 圆形渲染 |
| `compText` | `(t: Str, size: Rat): Any` | 文本渲染 |
| `compColorHex` | `(hex: Str): Any` | 颜色：`#rgb`/`#rrggbb` 或 10 个命名色（`red/green/blue/white/black/yellow/magenta/cyan/gray/orange`） |
| `compArea` | `(): Any` | 碰撞区域（参与碰撞检测的前提） |
| `compBody` | `(): Any` | 物理刚体（配合 `gameGravity` 受重力） |
| `compSolid` | `(): Any` | 静态实心（平台、墙壁） |
| `compTag` | `(t: Str): Any` | 标签组件（等效 `objTag`） |
| `compAnchor` | `(a: Str): Any` | 锚点（`"topleft"/"center"/"center"` 等，见 KAPLAY 文档） |

对象操作：

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `objAdd` | `(): Any` | 创建空对象 |
| `objUse` | `(o: Any, c: Any): Null` | 给对象挂组件（字符串参数=标签） |
| `objDestroy` | `(o: Any): Null` | 销毁对象 |
| `objExists` | `(o: Any): Bool` | 对象是否仍存在 |
| `objSetPos` | `(o: Any, x: Rat, y: Rat): Null` | 直接设定位置 |
| `objSetScale` | `(o: Any, s: Rat): Null` | 直接设定缩放 |
| `objMove` | `(o: Any, dx: Rat, dy: Rat): Null` | **位置增量**：立即位移 `(dx, dy)` 像素（不是速度；配合 `onUpdate` 里乘 `dt` 实现「像素/秒」） |
| `objPos` | `(o: Any): Any` | 取位置 Vec2 |
| `objTextSet` | `(o: Any, t: Str): Null` | 改文本对象的文本 |
| `objTag` | `(o: Any, t: Str): Null` | 给对象加标签（用于分组碰撞与查询） |
| `spriteLoad` | `(name: Str, src: Str): Null` | 载入精灵图（`assets/...` 相对路径，相对网页所在目录） |
| `vecX` | `(v: Any): Rat` | Vec2 的 x |
| `vecY` | `(v: Any): Rat` | Vec2 的 y |

便捷封装（`sprite.subl` 里带体的工具函数，用上述原语组合）：

| 函数 | 说明 |
| --- | --- |
| `spriteAdd(name, x, y)` | `objAdd` + `compSprite` + `compPos`，返回对象 |
| `shapeAdd(x, y)` | `objAdd` + `compPos`，返回对象 |
| `rectAdd(w, h, x, y, hex)` | 矩形色块（`compRect` + `compColorHex`） |
| `circleAdd(r, x, y, hex)` | 圆形色块 |
| `textAdd(t, x, y, size)` | 文本对象 |
| `objAddArea(o)` | 等效 `objUse(o, compArea())` |
| `objLeft(o)` / `objTop(o)` | 取左/上坐标（`vecX/vecY` 的封装） |

### 输入（`input.subl`）

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `onKeyDown` | `(key: Str, body: (Any) => Null): Null` | **按住**期间每帧触发 |
| `onKeyPress` | `(key: Str, body: (Any) => Null): Null` | **按下瞬间**触发一次 |
| `onKeyRelease` | `(key: Str, body: (Any) => Null): Null` | **松开**时触发 |
| `onMouseDown` | `(btn: Str, body: (Any) => Null): Null` | 鼠标键按下（`"left"/"right"/"middle"`） |
| `mousePosX` | `(): Rat` | 鼠标 x |
| `mousePosY` | `(): Rat` | 鼠标 y |

键名用小写单词：`"left"/"right"/"up"/"down"/"space"/"enter"/"a"...`（KAPLAY 键名）。

### 主循环与计时（`loop.subl`）

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `onUpdate` | `(body: (Rat) => Null): Null` | 每帧调用，参数 `dt`（秒） |
| `frameDt` | `(): Rat` | 当前帧间隔（秒） |
| `every` | `(secs: Rat, body: (Any) => Null): Null` | 每 `secs` 秒重复 |
| `after` | `(secs: Rat, body: (Any) => Null): Null` | `secs` 秒后一次 |

### 碰撞与查询（`collision.subl`）

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `objOnCollide` | `(o: Any, tag: Str, body: (Any) => Null): Null` | `o` 与带 `tag` 的对象碰撞时触发（双方都要 `compArea`） |
| `objIsColliding` | `(a: Any, b: Any): Bool` | 两对象当前是否重叠 |
| `objsByTag` | `(t: Str): List[Any]` | 按标签查对象列表 |
| `objsDestroyTag` | `(t: Str): Null` | 按标签批量销毁 |

## 写游戏的套路

```subl
@impure
fun main(): Null {
    gameStart(640, 480)                      // 1. 启动
    spriteLoad("bean", "assets/bean.png")    // 2. 资源
    @mut var score: Int = 0                  // @mut 才能被 lambda 改写
    val player: Any = spriteAdd("bean", 300.0, 400.0)
    objAddArea(player)                       // 3. 要碰撞就挂 area
    onKeyDown("left") { _e => objMove(player, -6.0, 0.0) }
    every(1.0) { _e => { score = score + 1 } }
    onUpdate { _dt => ... }                  // 4. 每帧逻辑
    objOnCollide(player, "enemy") { _o => ... }   // 5. 碰撞
    null
}
```

完整示例见 `app/main.subl`（豆豆躲方块：移动、刷怪、计分、碰撞结束、空格重开）。
